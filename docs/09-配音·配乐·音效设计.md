# 配音 · 配乐 · 音效设计手册

> 短剧的完播率有一半是声音决定的。本片的声音设计遵循一条原则：**画面负责好看，声音负责好哭。**

### 1.2 配音的三条硬规则

1. **金花的台词永远比对手戏低半个音量**。她的力量来自"你必须仔细听"，不是"她很大声"。
2. **所有虚弱、垂死、遗言的台词，必须录出真实的换气声**（E3、E4、E8）。宁可 NG 十次，也不要用 AI 平滑掉的完美气息。**换气声就是生命体征。**
3. **林晓的 VO 和林晓的台词是两种声音**。台词是"她在剧里说话"，VO 是"她在跟观众说话"。混音时 VO 要更近、更干、更贴耳（加 2dB，减少混响）。

## 二、配乐（BGM）

### 2.1 乐器编制

**核心乐器（贯穿全片）**：
- **古筝**——现代线与文化主题
- **箫**——孤独、山野、留白
- **二胡**——兄妹情、悲怆
- **芦笙**——苗族身份标签（**只在苗寨、上堡、现代节日出现，古代汉地场景禁用**）
- **木叶**——现代节日段落
- **牛角号**——苗家援军 / 集结（E4、E6、E7）
- **牛皮鼓 / 战鼓**——紧张与爆发
- **女声无词吟唱（苗族音阶）**——**全片的灵魂动机**

**辅助**：低音大提琴（压迫）、弦乐组（情绪推升）、80Hz sub bass（钩子音）。

### 2.2 主题旋律系统（三条动机贯穿全片）

| 动机 | 名称 | 乐器 | 首次出现 | 再现位置 | 含义 |
| --- | --- | --- | --- | --- | --- |
| **A** | 「乌饭动机」 | 女声无词吟唱（4 小节，五声音阶，级进下行） | E2（锅中米变黑） | E7（供桌千碗）、E9（白瓷碗乌饭与云海幻影）、E10（完整苗歌版） | **全剧最重要的动机。** 它跟着“乌饭”这个物件走，从一碗到千碗，从北宋到今天 |

## 四、混音规范

| 声道层 | 音量基准 | 说明 |
| --- | --- | --- |
| 对白 / VO | -6 dBFS（峰值 -3） | 永远是最清晰的一层 |
| 关键音效 | -10 dBFS | 放大处理的音效可到 -6 |
| 环境音 | -22 dBFS | 铺底，不抢戏 |
| 音乐 | -18 dBFS（高潮时 -12） | 有对白时自动 ducking -6dB |
| 整体响度 | **-14 LUFS** | 抖音/视频号标准 |
| 真峰值 | ≤ -1 dBTP | 防止削波 |

### 混音三条铁律

1. **有台词时音乐必须让路**（侧链压缩，-6dB，attack 20ms，release 300ms）。观众听不清台词，短剧就死了。
2. **低频只留给三样东西**：钩子的"咚"、战鼓、心跳。其余全部高通滤波 80Hz 以上，保证手机外放清晰。
3. **手机外放测试是最终验收标准**。所有混音成品必须用手机外放（不戴耳机、音量 60%）听一遍，听不清的地方一律重混。

## 五、AI 配音的常见问题与解决

| 问题 | 表现 | 解决方案 |
| --- | --- | --- |
| 情感平 | 悲伤台词听起来像播报 | 把长句拆成短句分段生成，再手动拼接并调整间隔 |
| 换气假 | 虚弱台词一气呵成 | **手动在句间插入真实录制的换气音**（可用自己的呼吸声录制） |
| 语速匀 | 全句一个速度 | 在关键词前后手动插入 0.15–0.3s 静音，制造重音 |
| 尾音飘 | 句尾莫名上扬 | 在文本末尾加句号并降低"活力"参数 |
| 古今混杂 | 现代语调念古文 | 金花/文广的台词用"戏剧朗诵"预设，林晓用"自然口语"预设 |
| 哭腔过度 | 一哭就含混 | **规定：任何角色的哭戏，字词清晰度优先于情绪浓度。** 听不清的哭 = 无效的哭 |
