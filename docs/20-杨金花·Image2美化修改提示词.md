# 杨金花 · Image2 美化修改提示词

垫**已经生成好的杨金花图**做修改，不要重抽一张新脸。

目标：大的五官骨架不动，去掉路人感，更美丽，性格坚韧，三秒能被记住。  
不是网红脸，不是甜妹，不是换脸。

**Image2 怎么用**
1. 上传现有金花图做参考 / 垫图。
2. 只复制下面一条灰框。
3. 变化程度、重绘幅度开 **30%–40%**。再高会换脸，再低看不出美化。
4. 先跑「面部特写」锁一张，再拿这张去改半身和五套状态。

**必须保留**  
瓜子脸、颧骨位置、细长丹凤眼内双、直鼻、薄唇、暖麦色、右后扁圆低髻、银牌、杨桐叶银簪、簪尾两粒小银铃、小银梳、齐腰靛蓝短衣。

**只改这些**  
眉眼更清楚、眼神有锋、皮肤细腻透光、唇峰清楚、下颌利落、去掉疲态和路人感。

**观众记忆点（三件套，每条都要出现）**
1. 眼：丹凤眼尾微扬，深黑瞳，沉静带锋，不笑不娇。
2. 耳：左耳后一道浅旧疤，耳朵外露。
3. 簪：叶形银簪 + 两粒小银铃。
