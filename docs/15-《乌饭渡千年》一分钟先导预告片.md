# 《乌饭渡千年》一分钟先导预告片

> 依据 `docs/13-《乌饭渡千年》十集纯文字剧本.md` 最新剧情编写。

## 产物一：纯文字预告台本

林晓旁白：湖南绥宁，有一个只属于女子的千年节日。

△ 晨雾中的大园古苗寨。汉服女生林晓独自走入青石巷，停在斑驳古碑前。

△ 她的指尖抚过凹陷的“杨金花”三字。金光炸开，整座古寨开始扭曲。

林晓：（惊愕）这是……穿越？

△ 北宋山林。背着竹篓的杨金花从雾中跑来，眼眶通红，却没有停下。

杨金花：我兄长杨文广被奸臣陷害，打入柳州死牢。再不救，他便撑不到行刑之日！

△ 杨桐叶汁滴进白米。米粒由白转青，再变成乌黑发亮。

狱卒：（厉声）站住！这黑饭有毒！

△ 杨金花当众抓起一把乌饭放入口中，直视对方，没有退。

杨金花：若有毒，我先死。

△ 枷锁中的杨文广接过那碗黑饭。涣散的目光，一点点重新燃起。

△ 木栏断裂。火光冲天。兄妹杀出死牢。

△ 城门巷口，一支冷箭直射杨文广后心。他专注迎敌，毫无察觉。

△ 杨金花毫不犹豫扑出，推开兄长，自己转身挡在箭路上。

杨文广：（失声）金花——！

△ 远山垭口，缉捕军火把连成一条火蛇，正向苗寨逼近。

△ 伤未愈的杨金花站上石阶，举起那碗乌饭。

杨金花：四月初八，我要做一件惊天动地的事。

△ 现代长桌宴上一闪：母亲把第一碗乌饭推向归家的女儿。

林晓旁白：一碗乌黑怪饭，何以逆天改命？

绥宁四八姑娘节 · 十集穿越古风短剧

## 声音设计

| 时段 | 音乐 | 关键音效 | 对白处理 |
| --- | --- | --- | --- |
| 01–03 | 极轻箫声 + 低鸣 | 指腹摩碑、金光低频“嗡” | 开场旁白放慢、贴耳 |
| 04–06 | 木杵节奏进入 | 叶汁滴落、米粒变黑的细响 | 金花台词压低半个音量 |
| 07–10 | 鼓点加快 | 枪杆挑布、吞咽、木栏断裂 | “有毒”与“我先死”对切 |
| 11–13 | **3 秒绝对静音**后爆发 | 箭破空、闷响、文广破音呼喊 | 挡箭段落先静后炸 |
| 14–16 | 战鼓 + 号角 | 火把、铜锣、盟誓拍案 | “四月初八”四字加重 |
| 17–19 | 音乐抽空，只留一声碗响 | 白瓷碗触木桌 | 终钩旁白几乎是耳语 |

旁白与台词去标点后约 78 字，60 秒内平均 1.3 字/秒，以画面和停顿为主，不靠解说灌信息。

## 剪辑与悬念规则

1. **前 3 秒必须有画面**：古寨航拍直接起，不要片头 Logo。
2. **每 8–10 秒给一个新问题**：谁是杨金花 → 黑饭为何能救命 → 她能不能活 → 四月初八要做什么。
3. **挡箭用本片唯一慢镜**，前后都是快切，形成“突然变慢”的停顿感。
4. **金花在 16 镜只摇晃、不倒下**，把正片泪点留给第八集。
5. **17 镜现代乌饭只闪 3 秒**，不展开节日，让观众自己问“这和刚才那碗饭是不是同一件事”。
6. **结尾必须停在问句上**，不要解答，不要出现“全剧终”。
