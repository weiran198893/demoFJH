# 第四集《里应外合·血战突围》· 逐镜头分镜脚本

**总时长 58.0 秒 ｜ 14 个镜头 ｜ 主色：赤红（辅：玄黑、冷月白、靛蓝）**  
**核心任务**：把「救人」讲清楚——谁放火、谁从哪杀入、兄妹为什么必须走北门、金花为什么中箭、她把命交给谁。燃完必须心疼。  
**本集台词约 210 字**（旧稿只有 58 字，动作把故事吃掉了；这版每段对白都承担情节）。

> 金花 `{{金花·血战}}`（B-3）：4-01 至 4-10 **斗篷无血迹**；4-11 替兄挡箭后右后背才出现暗红晕。文广 `{{文广·战}}`：深褐皮甲半臂，弧形柳叶刀，不赤膊。林晓 A-2 沾尘态。全剧没有小孩。

## 本集导视（生成前必锁）

**故事效果**：上段让观众听懂计策、看见兄妹活着重逢；下段让观众明白——金花不是死在乱战里，是替兄挡箭。

**空间（死锁，全集成一套）**  
柳州北门内街巷，南北走向，约四十步长。  
- **北端**：城门楼 + 瓮城，包铁大门。伏兵藏在城门楼西侧马道阴影里。  
- **南端**：州牢大门，通向地下牢道。牢道由南向北通向街巷。  
- **西侧**：一条窄暗巷，金花伏兵处，巷口正对街巷中段。  
- **东侧**：关闭的木铺门板。  
轴线：会合后 **金花永远在画面左，文广永远在画面右**。撤退方向一律向北（城门）。

**人数（死锁）**

| 身份 | 人数 | 位置 |

| 杨金花 | 1 | 西巷→街巷左 |
| 杨文广 | 1 | 牢道→街巷右 |
| 林晓 | 1 | 西巷后段，不参战 |

**颜色**：4-01 冷月白 → 4-04 起朱砂红吃满 → 4-11 后每镜降饱和，交棒 E5 黛青。  
**光**：街巷火把从两侧店铺门口来，人物被橙红包裹；牢道主光仍在画面右下。  
**连贯**：同一轮冷月；金花斗篷中箭前干净；文广刀不换；林晓从西巷跟到北门，E5 才能出现在寨门口。冷箭打的是杨文广。

- **空间站位**：高机位俯瞰北门内。城门楼在画面上端（北），州牢在画面下端（南），西侧那条暗巷是一条更深的黑缝。城头 **4 名**持戈守军缓行，城楼 **1 名**更夫敲鼓，巷里 **2 名**巡夜提灯。人要小，城要完整。

## 三、本集制作要点

1. **4-01 与 4-04 同一张底图**，只改火。  
2. **林晓必须从 4-02 跟到 4-12**，E5 寨门口才能接上。冷箭打杨文广，金花推开哥哥、用后背挡箭。不要生成小孩。  
3. **中箭前斗篷干净，中箭后才有右后背暗红**。不要提前带血。  
4. **人数写死**：青壮 8、老妇 2、牢道官兵 3、街巷官兵 6、弓手 8。多一个都不要。  
5. **站位写死**：金花左、文广右、撤退向北。  
6. **动作碎切**（4-06）+ 音效节奏；不要生成 4 秒连贯对打。  
7. **4-11 静音不要填音乐。**  
8. 群戏前景必须有虚化遮挡。
