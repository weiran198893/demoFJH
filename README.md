## 快速上手（五步）

1. **读 `00` 号文件**，确定画幅、色彩章法与工作流。
2. **跑通风格码**：用 `00` 号文件 4.1 的 `{{风格}}` 宏生成一张满意画面，取其 `--sref`，此后全片不再更改。
3. **锁角色与场景**：按 `01`、`02` 号文件生成 24 张角色参考图与 12 张场景基准图，评审通过后才能进入下一步。
4. **按 `11` 号文件的批次计划出图**（**按场景批量生产，不按集数顺序**），再逐镜做图生视频。
5. **按 `09`、`10` 号文件完成声音、剪辑、调色、字幕与物料**，用 `10` 号文件第六章的验收清单逐项打勾。

## 全片速览

**剧情**：现代汉服女生林晓在绥宁大园古苗寨触摸刻有“杨金花”的古碑，穿越回北宋皇祐年间。杨家将后人杨文广遭虚构权臣“庞太尉”构陷入柳州死牢，其妹杨金花从黄桑携杨桐叶赶到柳州，以叶汁染米制成乌饭，利用狱卒怕毒不敢抢的心理送饭藏刀、救兄突围。金花护童中箭后，众人退回大园疗伤，再进入后世称为上堡古国的山地据点。农历四月初八，四方苗寨与东山侗族杨氏会盟；东山族人守北隘、护送通敌原件出围，苗侗乡亲坚守三个月，终于等来钦差废除伪令、平反撤军。金花因旧伤与操劳倒下，林晓回到现代，正赶上四八姑娘节盛况——一碗乌饭，渡了千年。

## 说明

本剧为艺术演绎，据湖南绥宁四八姑娘节民间传说改编。杨文广、狄青、侬智高为史实人物，杨金花救兄为民间传说；庞太尉及东山侗族杨氏守寨送信情节为艺术增写。全片无血腥暴力特写。上堡年代、民族服饰、节日起源及具体景点数据须在成片前由当地非遗保护单位或文化主管部门审看。
