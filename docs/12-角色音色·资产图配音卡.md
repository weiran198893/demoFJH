# 角色音色 · 资产图配音卡

> 出 Image2 角色资产图时，**半身像 + 底部音色条**一起生成，后面配音、对口型都认这张卡。  
> 声线以普通话为主，可带极淡地域底色，**不唱方言、不念苗歌腔、不用网络腔**。  
> 十集母稿已删除阿禾：小孩无对白，不出配音资产。杨守义为十集新增，必须出卡。

---

## 怎么用这张卡

1. **出图**：用下方「资产图文字条」贴进 Image2 提示词，9:16 竖图，人物占上 2/3，底部深色信息条占 1/4，白字清晰无错字。
2. **选声**：魔音工坊 / 火山语音按「AI 选声关键词」搜，对上「禁止」项再锁定。
3. **试音**：每个角色先录「试音句」，过耳后再批量。金花、文广、庞太尉三人必须一耳朵能分开。
4. **锁死**：试音通过后，该角色全片只用这一条声线；林晓对白和林晓 VO 是**同一张脸、两套声音预设**。

## B · 杨金花

全片灵魂声。日常轻柔，决断时**不提高音量，只把气息压住、把字咬实**。音量永远比对手戏低半档——力量来自「你必须仔细听」。

| 项 | 设定 |
| --- | --- |
| 年龄声线 | 20 岁青年女声，听感比实际年龄沉 |
| 音区 / 共鸣 | **中低音区，胸腔共鸣重**，喉位稳，头声极少 |
| 音色 | 不甜、不嗲、不幼；线干净，像绸不像糖；怒时仍平 |
| 语速 | 慢，3.0–3.5 字/秒；短句、实词；遗言更慢并留换气 |
| 口音 | 普通话为主，**极淡湘西南底色**：语调偏平、韵母略靠后，不卷舌夸张 |
| 音量 | 偏低；盟誓场可「清亮但不高亢」，禁止喊 |
| 参考感觉 | 舞台演员把生活句说清楚，不是戏曲青衣 |
| AI 选声关键词 | 年轻女声、中低沉、胸腔、沉稳、不甜美、戏剧生活感 |
| AI 参数 | 情感 70% · 语速 −15% · 音调 −3 |
| 状态变化 | 常态：轻而稳 / 夜采：气更沉 / 血战：气声耳语 / 伤后：气短带笑 / 盛装盟誓：清亮压住 / 遗言：换气断裂 |
