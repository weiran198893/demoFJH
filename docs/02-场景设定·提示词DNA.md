# S01 · 大园古苗寨古碑前

**空间概念**：一条被岁月磨得发亮的青石板巷，两侧是明清窨子屋的高耸马头墙（青砖黛瓦，墙面斑驳泛白），巷子窄而深，形成天然的"一线天"竖构图——**天生适配 9:16**。巷子尽头一棵老杨桐树，树下立一块半人高的青石古碑，碑面爬满青苔，"杨金花"三字被无数人指尖摩挲得发亮。

**关键陈设**：
- 青石古碑（碑体倾斜 5 度，碑首有缺角，碑面阴刻"杨金花"三字，字口内积着深绿苔痕）
- 老杨桐树（树干粗壮，深绿卵形叶，光斑从叶隙洒下）
- 窨子屋马头墙、木格花窗、褪色红灯笼
- 青石板路面缝隙里的青苔与野草

**光线**：上午 9 点侧逆光，光从巷子尽头打来，形成一道明亮的光带；巷内其余部分在阴影里。空气中有可见的**丁达尔光柱与浮尘**（运动锚点）。

**色彩**：青灰（墙）+ 苔绿（碑、苔）+ 一点褪红（灯笼）。饱和度整体压低 25%。

**`{{S01}}` 提示词宏：**
```

青砖黛瓦，白色墙面斑驳剥落露出砖体，木格花窗与褪色的红灯笼；

# S02 · 北宋绥宁山林

**空间概念（日）**：黎明的湘西南群山，层峦叠嶂消失在乳白色晨雾里。近景是枯黄的茅草坡与断枝，中景是杨桐灌木丛，远景是若隐若现的千年古寨轮廓（只见屋脊与炊烟）。**雾要浓，浓到能"吃掉"背景**——这是掩盖 AI 背景崩坏的最佳手段，也是《英雄》式留白。

**空间概念（夜）**：同一片山林，改为清冷月光。露水挂在叶尖反光，地面湿滑，雾变薄变蓝。远处有零星的萤火与几点寨火。

**关键陈设**：杨桐树丛（深绿卵形叶，成片）、山间羊肠小路、溪边石臼、临时窝棚（木架 + 茅草顶 + 一口铁锅 + 柴火堆）。

**光线**：
- 日：正逆光，太阳低角度从山脊后升起，雾被照亮成乳白发光体，人物成半剪影。
- 夜：冷调顶侧月光（色温 7500K），叶尖露水高光，柴火为唯一暖光源（3000K），形成**冷暖对冲**。

**`{{S02·日}}` 提示词宏：**
```
北宋时期湖南绥宁的黎明群山，层峦叠嶂消失在浓厚的乳白色晨雾中，
近景是枯黄茅草坡与散落的断枝落叶，中景成片的杨桐灌木丛深绿卵形叶片，
远景雾中若隐若现的千年苗族古寨轮廓，只见屋脊与升起的炊烟；
一条羊肠小路蜿蜒穿过草坡；
太阳刚从山脊后升起形成强烈逆光，浓雾被照亮成乳白色发光体，
景物呈层次分明的水墨剪影；苍茫、寂静、大面积留白，中国山水画意境
```

**`{{S02·夜}}` 提示词宏：**
```
北宋湖南绥宁的深夜山林，清冷月光穿过枝叶洒下斑驳光斑，
成片杨桐灌木深绿卵形叶片上挂满露水在月光下闪烁，地面湿滑覆盖苔藓与落叶，
薄薄的蓝色雾气贴地流动，远处几点萤火与山寨的零星火光；
溪边一座临时窝棚，木架茅草顶下一口铁锅架在柴火堆上，火焰是画面中唯一的暖光源；
冷调7500K月光与3000K橙色柴火强烈冷暖对冲，墨黑与月白主色调，幽静而紧张
```

# S03 · 柳州大牢

**空间概念**：北宋州级监牢。半地下结构，需下七级石阶。走廊狭长幽深，两侧是粗木栅栏囚室，顶部为粗糙拱形石顶，石缝渗水。墙上每隔三米一支火把，火把之间是完全的黑暗——**明暗交替的节奏本身就是构图**。地面是夯土与稻草，散落断草与陶碗碎片。

**关键陈设**：手臂粗的木栅栏（表面有抓痕与刻痕）、锈蚀铁锁与铁链、墙上的刑具阴影、稻草堆、木枷、乌饭竹篮（唯一的靛蓝色亮点）、渗水的墙面。

**光线**：**唯一光源是火把，来自画面右侧下方**（全片死锁），人物左脸永远在暗部，形成强烈的"半明半暗"脸——这正是《英雄》式的戏剧照明。火光**跳动**（运动锚点）。有从高处小气窗漏下的一道冷月光，与火光形成第二组冷暖对冲。

**`{{S03}}` 提示词宏：**
```
北宋州级地下监牢，狭长幽深的走廊，粗糙的拱形石顶，石缝渗水滴落，
两侧是手臂粗的木栅栏囚室，木栏表面布满抓痕与刻痕，锈蚀的铁锁与垂地铁链；
地面是夯土与散乱的稻草，散落断草与陶碗碎片；
墙上每隔三米插一支松脂火把，火把之间是完全的黑暗，明暗强烈交替；
高处一个小气窗漏下一道惨白的冷月光；
唯一主光源是画面右下方跳动的橙红色火把光，人物左侧面孔隐没在阴影中；
炭黑与火焰橙的强烈对比，空气中飘着尘埃与烟气，压抑、潮湿、绝望
```

# S04 · 大牢外街巷

**空间概念**：柳州古城的夜。青石板街巷，两侧是低矮的木构商铺（门板紧闭），巷口是高大的城门楼与瓮城。街巷被官兵的火把照成一条**赤红的光河**。远处城楼上有烽火与旗帜。

**关键陈设**：城门楼（厚重包铁木门、门钉）、兵器架、翻倒的货摊与滚落的陶罐、燃烧的草料垛、插在地上的箭矢、迎风狂舞的军旗。

**光线**：**满屏火把橙红**，从四面八方来，人物被多重红光包围；天空是深蓝夜色。烟雾大量弥漫（既是气氛也是遮丑）。

**`{{S04}}` 提示词宏：**
```
北宋柳州古城的夜晚街巷，青石板路面，两侧低矮木构商铺门板紧闭，
巷口矗立高大的城门楼与瓮城，厚重包铁木门布满门钉，城楼上军旗迎风狂舞；
数十支官兵火把把整条街巷照成一条赤红的光河，燃烧的草料垛升起浓烟与飞舞的火星，
翻倒的货摊与滚落的陶罐，插在地上的箭矢，兵器架散落一地；
深蓝色夜空与地面赤红火光形成强烈冷暖对撞，浓烟弥漫，
赤红主色调，混乱、激烈、战场感
```

# S05 · 大园古苗寨内

**空间概念（外）**：晨光中的窨子屋群落，33 栋明清古建连成青瓦的海，屋脊起伏如波浪，家家炊烟。青石巷道纵横，巷底有排水沟。寨门是一座木构门楼，挂着牛角与彩布。远处梯田与竹林。

**空间概念（内 · 火塘）**：苗家木屋堂屋，地面中央下沉一个方形火塘，塘中柴火燃烧，上方悬一口铁三脚架与吊锅，屋梁被烟熏得漆黑发亮，梁上挂着腊肉、干辣椒、草药束。四周是原木墙板与竹编器物。

**关键陈设**：火塘、吊锅、腊肉与草药串、苗药石臼、粗陶碗、竹编簸箕、木凳、杨氏宗祠牌匾与神龛、纺车。

**光线**：
- 外：晨光低角度斜射，屋顶青瓦泛冷蓝，炊烟被逆光照亮。
- 内：**火塘自下而上的暖橘光**为主光（打光方向罕见，戏剧感强），屋顶天窗漏下一道冷光作为轮廓光。

**`{{S05·外}}` 提示词宏：**
```
中国湖南绥宁大园古苗寨全景，33栋明清窨子屋连成青瓦的海洋，屋脊起伏如波浪，
青砖黛瓦马头墙，家家屋顶升起炊烟，青石板巷道纵横交错；
一座木构寨门门楼挂着牛角与彩色布条，远处是层层梯田与竹林；
清晨低角度斜射的金色阳光，青瓦泛出冷蓝色调，炊烟被逆光照成半透明的金色；
黛青与暖金对比，古朴、宁静、千年时光沉淀感
```

**`{{S05·火塘}}` 提示词宏：**
```
苗家木屋堂屋内景，地面中央下沉一个方形火塘，塘中柴火熊熊燃烧并升起火星，

# S06 · 黄桑原始林海

**空间概念**：联合国誉为"神奇绿洲"的原始次生林。参天古木遮天蔽日，只有零星光柱穿透林冠射到覆满苔藓的地面。空气中永远有**水雾与浮游光尘**。三个标志性点位：

1. **曲幽谷**：3.5 公里峡谷，木栈道沿溪蜿蜒，两侧岩壁覆满蕨类与苔藓，溪水清澈见底。
2. **六鹅洞瀑布**：30 米高瀑布飞流直下，砸入碧潭激起大片水雾，晴日水雾中现彩虹。
3. **楠木王**：需数人合抱的千年楠木，树皮沟壑纵横，板根如墙。

**光线**：林冠漏下的**上帝之光**光柱（丁达尔效应拉满），地面大部分在幽暗的绿影中。瀑布处逆光，水雾被照亮成白色发光体。

**`{{S06·林海}}` 提示词宏：**
```
中国湖南绥宁黄桑原始次生林海，参天古木遮天蔽日，树干覆满厚厚的苔藓与藤蔓，
地面铺满苔藓、蕨类与腐叶，无数道金色光柱穿透林冠射到林间地面，
空气中弥漫着水雾与漂浮的光尘；一条清澈溪流在苔石间蜿蜒；
翠碧绿主色调，强烈的丁达尔光效，深邃、壮美、原始、神秘的绿洲
```

**`{{S06·曲幽谷}}` 提示词宏：**
```
黄桑曲幽谷峡谷，一条木栈道沿着溪流蜿蜒深入峡谷，两侧陡峭岩壁覆满蕨类与苔藓，
古树枝叶在头顶交织成绿色穹顶，溪水清澈见底可见卵石，
光线被层层枝叶过滤成幽绿色，空气清凉有薄雾；深绿主色调，幽深清凉，武侠意境
```

**`{{S06·六鹅洞瀑布}}` 提示词宏：**
```

激起漫天白色水雾弥漫整个画面，阳光穿透水雾形成一道彩虹，
崖壁湿滑黝黑覆满苔藓与藤蔓，潭边散落巨大的黑色卵石；
逆光拍摄，水雾被照亮成发光的白色帷幕，翠绿与雾白主色调，壮美、震撼
```

# S07 · 上堡古国

**空间概念**：海拔 800 米山巅的苗族古寨——苗族历史上第一个国都。**三纵四横**的木屋格局（三条纵街、四条横巷），层层吊脚楼依山而建。中心是一座三层木构鼓楼，飞檐层叠，楼中悬一面大牛皮鼓。鼓楼前是一片夯土广场。四周是云海翻涌的群山。

**关键陈设**：鼓楼与大鼓、广场中央的长条供桌（一排排乌黑的乌饭陶碗）、四方苗寨首领的木凳与旗帜、竖立的图腾木柱（蝴蝶妈妈纹）、明黄经幡与彩布、盟约用的兽皮卷与朱砂。

**光线**：正午顶光，高原强光，明黄经幡与银饰强反光。云海反射天光，画面整体明亮通透——**与前六集的幽暗形成强烈反差，这是"翻案"的视觉表达**。

**`{{S07}}` 提示词宏：**
```
中国湖南绥宁上堡古国，海拔800米山巅的苗族古寨，苗族历史上第一个国都，
三纵四横的木屋格局，层层吊脚楼依山而建，木板被岁月熏成深褐色；
寨子中心矗立一座三层木构鼓楼，飞檐层层叠叠，楼中悬着一面巨大的牛皮鼓；
鼓楼前是夯土广场，广场两侧竖立着雕刻蝴蝶妈妈图腾的木柱，
明黄色经幡与彩布在山风中猎猎飘扬；四周群山云海翻涌；
正午高原强烈顶光，明黄与赤金主色调，庄严、壮阔、神圣的仪式感
```
