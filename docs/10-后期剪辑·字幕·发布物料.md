### 1.2 转场规范

| 转场类型 | 使用场合 | 全片使用次数 |
| --- | --- | --- |
| **硬切（Cut）** | 默认转场，占 90% | 约 100 次 |
| **前景遮挡切** | 树枝/人影划过镜头时切 | E2-02、E4-07、E4-09 |
| **白闪（Flash to White）** | 仅穿越使用 | 2 次（E1 穿越、E8 回归） |
| **淡入淡出（Fade）** | 仅重大情绪断点 | E4 中箭、E5 疗伤开场、E9 剧情落版、E10 全剧落版 |
| **音效先入（J-Cut）** | 下一镜的声音提前 0.3–0.5s 进入 | E1-08→1-09、E5-11→5-12 等约 10 处 |
| **画面先出（L-Cut）** | 上一镜的声音延续到下一镜 | 情感镜头后常用 |

> **禁用**：叠化（除幻影外）、翻页、缩放转场、任何"抖音特效转场"。**古风短剧一旦用花哨转场，格调立刻塌掉。**

### 1.3 剪辑的五条实战规则

1. **每集的第一帧必须是画面，不是 LOGO、不是片头**。短剧没有片头的空间，观众划走只需要 1.5 秒。
2. **台词说完后留 0.3–0.5 秒再切**，让表情"落地"。唯一例外是快节奏对切（E1-12、E1-14），说完立刻切。
3. **音乐的强拍要与剪辑点对齐**。特别是 E2-05（木杵节拍）、E4-06（动作三连）、E7-07（盟印 + 信筒 + 密道三连）。
4. **AI 生成的视频，前 6 帧和后 6 帧一律裁掉**。模型在片头片尾容易出现畸变、闪烁、突然加速。
5. **一个镜头如果生成了 10 版都不满意，就改分镜**，不要硬凑。用两个更简单的镜头代替一个复杂镜头，永远是对的选择。

## 二、调色规范

### 2.1 全片统一底层（所有素材第一步）

```
1. 曝光归一：把所有素材的中灰点对齐到 IRE 45
2. 白平衡统一：按场景锁定（见下表）
3. 挂载基础 LUT：Kodak 2383 Film Emulation（强度 65%）
4. 加胶片颗粒：35mm，强度 8%，尺寸 1.2
5. 暗角：-12，羽化 60%
6. 轻微色差（Chromatic Aberration）：0.8px（仅古代线）
```

### 2.2 分集色彩参数

| 集 | 主色 | 色温 | 色调 | 饱和度 | 对比度 | 特殊处理 |
| --- | --- | --- | --- | --- | --- | --- |
| E1 | 青灰苔绿 → 鎏金 | 5200K | +2 绿 | -25% | 中 | 1-04 至 1-07 金色曲线做平滑抛物线 |
| E2 | 墨黑月白 | 7200K | -3 蓝 | **-40%** | 高 | 全片饱和度最低；柴火区域单独 +15% 暖 |
| E3 | 炭黑火橙 | 3200K | +4 橙 | -15% | **最高** | 高光只给火，暗部压到 IRE 8 |
| E4 | 赤红 | 3000K | +8 红 | **+20%** | 高 | 4-11 后每镜红色饱和度递减 8% |
| E5 | 黛青 + 暖橘 | 外 5800K / 内 2800K | 分区 | -10% | 中低 | 5-12 门外光调到 8000K 制造冷色入侵 |

### 2.3 一致性检查（每集交付前必查）

- [ ] 同一场景的镜头，肤色是否一致（用示波器矢量图检查肤色线）
- [ ] 靛蓝的色相是否全片统一（HSL 取样，色相值偏差 ≤ 3）
- [ ] 乌饭的黑是否全片统一（RGB 值应在 18/16/14 附近，**不是纯黑**）
- [ ] 银饰的高光是否过曝（不得超过 IRE 98）
- [ ] 黑位是否统一（暗部最低点 IRE 3–5，不要死黑）

## 三、字幕规范

### 3.1 对白字幕

| 项目 | 规格 |
| --- | --- |
| 字体 | 思源黑体 CN Medium（**对白用黑体，保证小屏可读**） |
| 字号 | 竖屏 54px（1080×1920），横屏 42px |
| 颜色 | 纯白 `#FFFFFF` |
| 描边 | `#000000`，3px，不透明度 70% |
| 阴影 | 偏移 2px，模糊 4px，不透明度 40% |
| 位置 | 竖屏：底部安全区上方 380px（避开平台 UI）；横屏：底部 120px |
| 行数 | **最多 2 行**，每行最多 14 字 |
| 单条停留 | ≥ 1.2 秒 |
| 淡入淡出 | 无（硬切，保证与语音精确同步） |

### 3.2 钩子字幕（每集片尾）

| 项目 | 规格 |
| --- | --- |
| 字体 | **方正清刻本悦宋简体**（备选：思源宋体 Heavy） |
| 字号 | 主句 96px，副句（"第 X 集 完"）40px |
| 颜色 | 米金 `#F5E6C8` |
| 描边 | `#1A1A1A`，2px |
| 投影 | 偏移 0，模糊 12px，`#000000` 30% |
| 位置 | 画面正中，占宽 78% |
| 动画 | 0.3s 淡入 + 缩放 1.06→1.00（缓出）；停留 1.9s；0.3s 淡出 |
| 背景 | 纯黑 + 一层极淡的乌饭碗轮廓水印（不透明度 6%） |

### 3.3 VO 字幕与信息字幕

- **VO 字幕**：与对白字幕同规格，但颜色改为 `#F5E6C8` 米金，以区分"画外音"。
- **景点信息字幕**（E5、E6、E9、E10）：右下角浮出，思源宋体 Medium，36px，米金色，格式：

  > **大园古苗寨**
  > <sub>湖南绥宁 · 江南最大苗族古建筑群</sub>

  停留 2.5s，从右侧滑入 0.4s，淡出 0.3s。

### 3.4 合规角标（全片常驻）

- 位置：右下角，距边 24px
- 字号：18px，颜色 `#FFFFFF` 不透明度 35%
- 内容：`本剧为艺术演绎 · AI 辅助生成`
- E1 首镜与 E10 落版处，额外出现完整声明（见 `00-总纲` 第七章）

## 五、AI 视频常见崩坏与救火方案

| 崩坏类型 | 典型表现 | 救火方案 |
| --- | --- | --- |
| **手指崩坏** | 六指、手指融合 | ① 提示词加"手放在身后/袖中" ② 用景别回避（改中景以上）③ 后期用局部重绘修单帧再补帧 |
| **人脸漂移** | 同一角色前后不像 | 严格用角色参考图 + `--cw 80`；同场景镜头**一次性批量生成**，不要隔天补 |
| **多人崩坏** | 群像中出现畸形人 | **前景遮挡 + 浅景深虚化 + 逆光剪影**，三招并用；人数超 5 人一律虚化处理 |
| **服装变化** | 银饰数量/衣纹突变 | 按"服装状态表"逐套出参考图；同一状态的镜头集中生成 |
| **运动崩坏** | 人物滑步、肢体穿模 | 一个镜头只写一种运动；复杂动作改为"起势 + 结果"两个镜头 |
| **文字乱码** | 石碑/圣旨上的汉字变形 | **所有画面内文字一律后期加**，生成时提示词写"石碑上无文字" |
| **武器崩坏** | 刀变形、多柄刀 | 武器只在特写与剪影中出现；中远景不给武器细节 |
| **光线跳变** | 同场景明暗不一 | 场景基准图垫图 + 后期逐镜匹配 |
| **画面闪烁** | 视频首尾帧抖动 | 裁掉首尾各 6 帧；必要时用光流补帧稳定 |
| **动物/群众穿模** | 飞鸟、人群穿过实体 | 尽量用远景与剪影；近景禁止出现复杂群体运动 |

## 六、验收清单（每集交付前逐项打勾）

**画面**
- [ ] 总时长在 50–58 秒之间
- [ ] 第一帧即为正片画面，无片头
- [ ] 无崩坏手/脸/肢体
- [ ] 无现代穿帮物（古代线）
- [ ] 角色形象与参考图一致
- [ ] 本集主色统治画面 70% 以上
- [ ] 至少有 1 个大远景 + 1 个大特写

**声音**
- [ ] 台词清晰，手机外放测试通过
- [ ] 整体响度 -14 LUFS，真峰值 ≤ -1 dBTP
- [ ] 有台词处音乐已 ducking
- [ ] 片尾钩子音效完整（咚 + 铜铃 + 专属回响）

**字幕**
- [ ] 对白字幕与语音精确同步（误差 ≤ 100ms）
- [ ] 无错别字（特别注意：窨子屋、六鹅洞、上堡、巫水、侬智高）
- [ ] 字幕未被平台 UI 遮挡（用真机预览确认）
- [ ] 合规角标常驻

**剧作**
- [ ] 开头 3 秒承接上集悬念
- [ ] 结尾钩子字幕正确
- [ ] 本集文旅植入信息已覆盖（对照 `00-总纲` 第六章）

**合规**
- [ ] 无血腥、无断肢、无面部创伤
- [ ] 反派只以官职称呼
- [ ] 苗族服饰为湘西南花苗样式，无支系误植
- [ ] AI 生成声明已标注
