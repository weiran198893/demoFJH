## 二、美学总纲：张艺谋《英雄》式东方色块美学

### 2.1 五条铁律

1. **一集一主色**——每集由一个主色统治画面 70% 以上面积，其余为对比色点缀。观众滑动时间线时，靠颜色就能记住"第几集"。
2. **大面积单色留白**——雾、烟、水、布、林、火，用大块单色填满画面，人物只占画面 1/5–1/3，突出"人在天地间"的孤勇感。
3. **对称与中心构图**——重要人物、重要道具（乌饭碗、古碑、鼓楼）一律居中对称，仪式感优先于生活感。
4. **飘动的元素**——每个镜头至少有一样"在飘"：雾、纱、发丝、火星、落叶、水雾、稻穗、银饰流苏。AI 视频最怕"死画面"，飘动元素是运动的锚。
5. **慢镜头的克制使用**——只在三处用极慢镜（0.25 倍速）：金花中箭护童（E4）、乌饭入口（E3）、金花倒下金光涌起（E7）。用少才有力量。

### 2.2 色彩章法（全片色彩剧本）

| 集 | 主色 | 辅色 | 情绪 | 色彩动机 |
| --- | --- | --- | --- | --- |
| E1 千年秘史 | **青灰 + 苔绿**（现代）→ **鎏金白**（穿越） | 藕荷（林晓服） | 神秘、恍惚 | 苔绿=千年沉睡，鎏金=时空开启 |
| E2 深山寻叶 | **墨黑 + 月白** | 靛蓝、青汁绿 | 冷静、机谋 | 黑是全片的"戏眼"——乌饭之黑 |
| E3 智闯牢狱 | **炭黑 + 火把橙** | 血锈红 | 压抑、爆发 | 黑牢中一点橙火 = 绝境中一线生 |
| E4 血战突围 | **赤红** | 玄黑、冷月白 | 燃烈、揪心 | 红=火、血、命 |
| E5 苗寨疗伤 | **黛青 + 火塘暖橘** | 草药黄绿 | 温暖、后怕 | 青瓦的冷 vs 火塘的暖 |
| E6 黄桑秘境 | **翠碧绿** | 水雾白、岩灰 | 壮美、蓄势 | 绿=生机与庇护 |
| E7 姑娘节诞生 | **明黄 + 赤金** | 银白（银饰） | 庄严、悲壮 | 皇权之黄 + 民心之金 |
| E8 山河不负 | **靛蓝 + 银白 + 暖金** | 节庆红 | 治愈、升华 | 苗家靛蓝回到现代，落日暖金收尾 |

> **调色执行**：先按主色打底（Lift/Gamma/Gain 整体偏移），再用 HSL 限定把非主色区域降饱和 20–40%，让主色"吃掉"画面。全片统一挂一层 35mm 胶片颗粒（强度 8%）与轻微暗角（-12）。

### 2.3 镜头语言规范

- **景别配比**：远景/大远景 20%、全景 15%、中景 25%、近景 20%、特写/大特写 20%。每集必须有 **1 个大远景（山河）+ 1 个大特写（眼睛或手）**。
- **运镜库**（分镜中只允许使用以下命名，便于统一执行）：
  - `推镜 Push-in` / `拉镜 Pull-out` / `横移 Truck` / `升降 Pedestal` / `环绕 Orbit`
  - `跟随 Follow` / `手持微晃 Handheld` / `固定 Static` / `摇镜 Pan` / `甩镜 Whip Pan`
  - `变焦推 Dolly Zoom`（全片仅 E1 穿越、E7 金花倒下 两次使用）
- **AI 视频运镜提示词铁律**：**一个镜头只写一种运动**。同时写"推镜+环绕+人物奔跑"必然崩坏。复杂调度请拆成两个镜头再剪接。
- **越轴管理**：对话戏（E1 林晓×金花、E3 兄妹）固定 180 度轴线，金花永远在画面左侧，对话方在右侧，保证 AI 生成的多镜头能剪到一起。

## 三、AI 生成工作流（标准作业流程）

```
① 角色三视图锁定  →  ② 分镜首帧图（文生图）  →  ③ 首帧图生视频（图生视频）
                                                        ↓
⑥ 交付           ←  ⑤ 剪辑/调色/音乐/字幕  ←  ④ 挑片重生成（合格率约 1/3）
```

### 3.1 工具建议（任选其一体系，不要混用画风）

| 环节 | 首选 | 备选 |
| --- | --- | --- |
| 角色/场景首帧图 | Midjourney v7（`--sref` 锁风格 + `--cref` 锁人脸） | 即梦 AI、Flux + LoRA、SDXL |
| 图生视频 | 可灵 AI 1.6+（首尾帧功能） | 即梦、Runway Gen-4、海螺、Vidu |
| 人物口型 | 可灵对口型 / HeyGen | 剪映数字人 |
| 配音 | 魔音工坊 / 火山语音 | ElevenLabs（中文情感稍弱） |
| 音乐 | Suno v4（中国风古筝+箫+苗族芦笙） | 版权曲库 |
| 剪辑 | 剪映专业版 / Premiere Pro | DaVinci Resolve（调色更强） |

### 3.2 一致性保障方案（本片成败关键）

1. **角色锁**：为每个角色先生成一张"标准正脸半身像"作为**主参考图**，全片所有镜头用 `--cref 主参考图 --cw 80`（Midjourney）或"角色参考"功能锁定。禁止中途换参考图。
2. **服装锁**：见 `01-人物设定` 中的"服装状态表"，每个阶段（干净/夜露/血污/绷带/盛装）单独出一张参考图，共 5 套金花参考图。
3. **风格锁**：先跑通 1 张满意画面，取其 `--sref` 风格代码，全片所有镜头共用同一个 `--sref`。**风格码写进每条提示词。**
4. **场景锁**：8 个主场景各出 1 张"场景基准图"，后续同场景镜头用该图做垫图（img2img，重绘幅度 0.5–0.65）。
5. **光线锁**：同一场景同一时间段的镜头，光线方向必须写死（例：`S03 柳州大牢：火把光来自画面右侧下方，人物左脸在暗部`）。

### 5.2 钩子字幕规范

- 字体：**方正清刻本悦宋简体**（备选：思源宋体 Heavy）

## 七、风险与合规

1. **历史标注**：全片首尾各出现一次浅色小字免责——"本剧为艺术演绎，人物情节基于绥宁四八姑娘节民间传说改编"。杨文广、狄青、侬智高为史实人物，杨金花救兄为民间传说，庞太尉为虚构反派（避免与历史人物"庞籍"混淆，片中只称官职不称全名的方案见 E7 备注）。
2. **暴力尺度**：无喷血、无断肢、无面部创伤特写。中箭镜头用"箭羽入画 + 身体一震 + 慢镜背影"表现，血迹仅衣物晕染。
3. **民族元素准确性**：苗族服饰采用**湘西南绥宁花苗**样式（靛蓝蜡染、银饰相对简约），**不得**使用黔东南施洞型大银角（那是另一支系），避免文化误植。
4. **AI 生成声明**：片尾角标"本片由 AI 辅助生成"。
