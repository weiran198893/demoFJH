# 第二集 · 镜01 / 镜03 Midjourney 提示词

对应 `docs/14` 第二集上段：

- **镜01**｜3秒｜航拍大远景｜横移：黄桑林海云雾流动，杨金花带林晓和两名苗寨脚夫沿湿润山路进入密林。
- **镜03**｜3秒｜特写蒙太奇｜固定：众人背着叶包越过昼夜交替的山脊。

风格一律 `chinese pastoral cinematic`。每条灰框整段复制、一次粘贴。  
日和夜拆开出，不要写在同一张里。画面里不要字幕、不要汉字。

人物只作远景色块：金花靛蓝、林晓月白藕荷、两名脚夫青褐，竹篓里是湿靛蓝布包着的深绿卵形叶。  
出一张满意的金花/林晓参考后，可在同一条末尾加 `--cref` 那张图。

竖屏短剧用 `--ar 9:16`。若只要横屏底板，把末尾改成 `--ar 16:9`。
