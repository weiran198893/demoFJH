# 第一集：千年秘史·一朝穿越

**16镜｜55秒｜上段 25秒 / 下段 30秒**

## 本集导视

本集故事效果：让观众在半分钟里完成“打卡游客 → 时空坠落”，再在半分钟里完成“遇见金花 → 听见一碗不敢抢的饭”。上段要神秘、失重；下段要共情、留下钩子。

颜色基调：上段现代：**青灰 + 苔绿**，林晓藕荷紫是唯一暖点；穿越瞬间改 **鎏金白**。下段北宋山野：**雾青 + 枯草褐**，金花靛蓝是锚点。禁用高饱和网红滤镜。

布光：上段：巷内顶光弱、两侧马头墙挡光，形成一线天；碑面用侧逆光让苔藓发暗、字口发亮。穿越用从碑面内部涌出的金光做唯一主光。下段：晨雾散射光，人物没有硬影；金花从雾里出来时，先见靛蓝后见脸。

镜头拍摄语言：上段以固定、缓推、升镜为主，把古寨拍成“会呼吸的文物”；穿越镜是全片第一次 **变焦推 Dolly Zoom**。下段改跟随与双人轴线：金花永远在画面左侧，林晓在右侧。一镜只写一种运动。签名镜头：指尖抚“杨金花”三字、白光涡、金花从雾中跑来。

### 上段｜01–08｜25秒

**节拍**：走进古寨 → 触碑 → 金光开时空 → 摔进北宋。

镜01｜3秒｜航拍大远景｜缓降
晨雾掠过大园古苗寨连片窨子屋，青砖黛瓦沿山势铺开，身穿浅色汉服的林晓独自走入青石巷，神情轻松好奇。

镜02｜3秒｜中景｜跟随
林晓举起手机环拍古建筑，边走边微笑；旁白：“湖南绥宁，有一个只属于女子的千年节日。”

镜03｜3秒｜特写｜缓推
青苔斑驳的古碑占满画面，林晓的指尖缓慢抚过凹陷的“杨金花”三字。

镜04｜3秒｜近景｜固定
林晓歪头端详碑文，眉间浮起疑惑，试探着再次触碰刻字。

镜05｜3秒｜大特写｜变焦推
指尖接触碑面的瞬间金光沿纹路蔓延，林晓瞳孔骤缩，表情由好奇变成惊愕。

镜06｜4秒｜全景｜环绕
白光炸开，古寨和青石巷扭曲旋转，林晓失去平衡后被卷入金色光涡。

镜07｜3秒｜大远景｜下降
北宋绥宁山林晨雾苍茫，林晓从半空跌落在枯草间，现代汉服与荒野形成强烈反差。

镜08｜3秒｜近景｜固定
林晓慌乱坐起查看手机，看到“无服务”后呼吸停顿，脸上的茫然逐渐变成不安。

### 下段｜09–16｜30秒

**节拍**：雾中遇金花 → 听兄长蒙冤 → 一碗不敢抢的饭。

镜09｜4秒｜远景转中景｜跟随
急促脚步从雾中逼近，背竹篓的杨金花跑上山路，靛蓝衣摆翻动，眼眶泛红、神色焦急。

镜10｜4秒｜近景｜固定
林晓迅速躲到树后屏住呼吸，探出半张脸观察并小声自语：“古装打扮……难道我穿越了？”

镜11｜4秒｜双人中景｜固定
林晓迟疑着走出树后，双手微抬表示没有恶意；杨金花警惕停步，林晓轻声问：“姐姐，你怎么哭了？”

镜12｜4秒｜杨金花近景｜缓推
金花眼含泪意却绷紧下颌，急声说：“我兄长杨文广忠良报国，却被奸臣陷害，打入柳州死牢。”

镜13｜4秒｜双人近景｜固定
金花握紧拳头继续说：“送去的吃食尽被狱卒夺走，再不救，他便撑不到行刑之日！”林晓听后瞪大眼睛。

镜14｜4秒｜林晓近景｜固定
林晓难以置信地上前半步，脱口而出：“杨文广？史书上的忠勇将军？”

镜15｜3秒｜杨金花中景｜摇镜
金花转头望向幽深山林，眼中悲伤沉下、决心升起，说：“我要做一碗他们不敢抢、不敢碰的饭，救我兄长。”

镜16｜3秒｜林晓近景转黑｜固定
林晓皱眉追问“什么样的饭”，画面随金花坚定目光切黑，字幕“一碗乌黑怪饭，何以逆天改命？”浮现。

# 第二集：深山寻叶·乌饭玄机

**15镜｜52秒｜上段 27秒 / 下段 25秒**

## 本集导视

本集故事效果：上段把“采叶赶路”做成解谜铺垫，让观众先看见手、叶、汁，再问“要做什么”。下段一次性揭开计策：黑不是脏，是护身符。结尾必须停在狱门被拦，把爽感压到下一集。

颜色基调：**墨黑 + 月白** 为主。上段林海用湿润墨绿，叶汁是唯一高饱和青绿。下段窝棚火光暖，白米被染黑是本集“戏眼”，黑要压过一切暖色。辅色：金花靛蓝、青汁绿。

布光：上段白天：林冠漏光，斑驳、潮、没有阳光直射人脸。蒙太奇转夜后，窝棚只留一盏豆火 / 柴火，主光从画面右下打向金花侧脸。叶汁与米的特写用顶侧光，让汁液发亮、米粒分得清。

镜头拍摄语言：上段：航拍进山 + 手部特写交替，少对白、多工序。下段：双人中近景锁轴线，金花在左、林晓在右；顿悟镜给林晓一个短促推镜。禁用晃得发晕的手持。签名镜头：叶汁入臼、白米转黑、篮盖被双手按死。

### 上段｜01–08｜27秒

**节拍**：入黄桑采叶 → 窝棚问计 → 汁浸白米 → “因为黑才有生机”。

镜01｜3秒｜航拍大远景｜横移
黄桑林海云雾流动，杨金花带林晓和两名苗寨脚夫沿湿润山路进入密林。

镜02｜3秒｜中景｜固定
金花半跪在灌木旁熟练采下杨桐叶，以湿润靛蓝布包紧，神情专注急切。

镜03｜3秒｜特写蒙太奇｜固定
金花掐开叶柄确认汁色，众人背着叶包越过昼夜交替的山脊，字幕“数日后·柳州城外”出现。

镜04｜4秒｜全景转近景｜缓推
月色下众人抵达临时窝棚，林晓弯腰喘气、盯着竹篓问：“姐姐，一路护着这些叶子，到底要做什么？”

镜05｜3秒｜手部特写｜缓推
金花解开湿布、掐开叶柄，鲜绿汁液沿叶脉滴入石臼，她确认叶片可用后轻轻点头。

镜06｜4秒｜中景｜固定
金花有节奏地捣碎叶片，边做边解释：“这是杨桐叶，山里人常用它染饭。”

镜07｜3秒｜特写｜固定
青绿叶汁浸透白色糯米，金花继续说：“捣出青汁，浸入糯米，饭便会慢慢变黑。”

镜08｜4秒｜林晓近景｜固定
林晓看看绿汁又看看白米，皱起整张脸问“黑饭？谁敢吃”，金花抬眼冷静回答：“就是因为黑，才有生机。”

### 下段｜09–15｜25秒

**节拍**：揭开“以丑藏善” → 乌饭出锅入篮 → 狱门被拦。

镜09｜4秒｜双人中景｜固定
金花手中木杵不停，沉声说：“白饭送进牢里，全被狱卒抢走；我兄长只靠稀水，已撑了七日。”

镜10｜4秒｜林晓近景｜缓推
林晓瞳孔一缩、猛然直起身，恍然喊道：“我懂了！饭越怪，他们越不敢抢！”

镜11｜3秒｜中景｜固定
金花将染过叶汁的糯米倒入锅中，火光照亮她苍白侧脸，她低声说：“以丑藏善，以暗救光。”

镜12｜4秒｜俯拍特写｜固定
锅中米粒随沸水翻滚，由白转青、转褐再变乌黑，林晓旁白：“一碗乌饭，是她赌命换来的生机。”

镜13｜4秒｜手部特写｜固定
金花把乌饭压实装篮、盖上靛蓝布，双掌重重按住篮盖，神情决绝。

镜14｜3秒｜大远景转中景｜跟随
火把通明的柳州大牢前，金花独自提篮上前，守卫横枪围拢并挑开篮布。

镜15｜3秒｜狱卒近景转黑｜固定
狱卒看见黑饭惊疑后退，厉声喊“这黑饭有毒！拿走，不许入内”，随即切黑并出现悬念字幕。

# 第三集：智闯牢狱·黑饭救忠良

**15镜｜55秒｜上段 26秒 / 下段 29秒**

## 本集导视

本集故事效果：上段用“当众入口”把毒饭谣言当场拆掉，观众先爽再心疼。下段把兄妹隔栏重逢做成全剧最安静的力量戏：吃饭、藏刀、约子时。结尾必须听见木栏断裂。

颜色基调：**炭黑 + 火把橙**。墙、栏、枷是死黑，火把是唯一活色。乌饭比环境更黑，入口时唇边一点油光即可。辅色：血锈红只留在文广旧伤上，不喷溅。

布光：牢门外交替火把，光硬、影子长。囚室主光来自画面右侧下方火把，文广左脸沉在暗部，金花蹲下时脸被栏影切开。乌饭入口与咀嚼特写用近火，照亮嘴和眼，不照亮全屋。

镜头拍摄语言：上段中近景对峙，少大远景。下段兄妹戏锁 180 度轴：金花在左、文广在右。全片第二次允许较近的大特写——文广眼神从涣散到聚焦。进食段不要手持晃。签名镜头：当众入口、铁镣手接碗、目光回神。

### 上段｜01–07｜26秒

**节拍**：当众试毒 → 获准进牢 → 隔栏递饭。

镜01｜4秒｜中景｜固定
守卫伸手抢篮，金花迅速后退护住竹篮，掀开蓝布并抓起乌饭当众入口，动作果断、表情镇定。

镜02｜4秒｜金花近景｜缓推
金花咽下乌饭直视守卫，说：“山野树叶染米，无毒无害；若有毒，我先死。”

镜03｜3秒｜群像近景｜横移
守卫面面相觑，有人嫌恶退开，金花继续恳求：“只求送给囚徒充饥。”

镜04｜3秒｜中景｜固定
狱卒侧身让路仍握枪盯防，呵斥“快去快回”，林晓想跟入却被横枪拦在门外。

镜05｜4秒｜全景｜缓推
火把摇曳的囚室里，杨文广满身伤痕、戴着枷锁，虚弱靠在潮湿石墙边。

镜06｜4秒｜双人中景｜固定
金花隔栏蹲下递饭，眼眶泛红却强忍泪意，说：“哥，我带了你能吃的饭来。”

镜07｜4秒｜双人近景｜缓推
金花把碗往前送，声音发颤却坚定：“你一定要撑住，活下去。”文广咬紧牙关缓缓抬手。

### 下段｜08–15｜29秒

**节拍**：乌饭入口回神 → 藏刀传防 → 掰栏约子时。

镜08｜4秒｜手部特写｜固定
文广戴铁镣的手接过乌饭，先稳住呼吸，再克制地一口口进食，全程不流泪。

镜09｜5秒｜大特写｜缓推
干裂嘴唇艰难咀嚼，文广握拳压住咳嗽继续吞咽，涣散目光逐渐聚焦。

镜10｜4秒｜中景｜固定
金花从竹篮假底取出布防纸条和布包短柳叶刀，迅速从木栏缝塞入兄长掌中。

镜11｜4秒｜双人近景｜固定
金花贴栏低声交代：“子时换防，北门起火，沿山北撤，刀在这里。”

镜12｜3秒｜特写｜固定
文广扫图后轻答“好”，将纸揉成小团吞下，又把短刀贴腕藏入袖内。

镜13｜3秒｜远景｜固定
狱卒脚步从牢道尽头逼近，金花迅速离开，文广重新靠墙闭目调息。

镜14｜3秒｜近景｜固定
更鼓响起，文广睁眼发力掰断木栏，木屑飞溅，他低沉说道：“今夜子时，哥便杀出去！”

镜15｜3秒｜黑屏字幕｜固定
断木落地声后画面切黑，字幕“重兵围困，兄妹如何突围？”出现。

# 第四集：里应外合·血战突围

**15镜｜55秒｜上段 30秒 / 下段 25秒**

## 本集导视

本集故事效果：上段把突围拍成“只救人、不恋战”的干净动作戏，爽在会合那一眼。下段把箭雨、挡箭、归根做成全剧最狠的翻转：金花替兄挡箭，不是替路人挡箭。全片唯一一段慢动作留给挡箭。

颜色基调：**赤红** 统治 70% 以上。火、烟、旗、土都偏橙红。金花靛蓝斗篷 / 衣摆是画面里唯一冷色，挡箭时必须被看清。辅色：玄黑夜空、冷月白只在城头一线。

布光：上段：城外伏击用剪影，火把在城墙上连成线。草料起火后主光改从火堆侧逆打，人物边缘镶红。下段箭雨迎着火光飞来；挡箭镜金花身体挡住火，兄长脸被火照亮。血是暗红晕染，不鲜、不喷。

镜头拍摄语言：上段：大远景铺城 → 中景部署 → 全景对打，运镜跟人不环绕。下段：远景箭雨后立刻切文广近景，再接 **0.25 倍慢镜** 挡箭，然后恢复常速接人。一镜一种运动。签名镜头：三堆火同时起、兄妹对视、金花转身挡箭。

### 上段｜01–08｜30秒

**节拍**：子时放火 → 文广破牢 → 兄妹会合北撤。

镜01｜4秒｜大远景｜缓推
夜色笼罩柳州城，城墙火把连成一线，金花带苗家援兵伏在城外暗处观察换防。

镜02｜4秒｜中景｜固定
金花扫过紧张的众人，压低声音部署：“子时点燃空草料垛，以烟火调开守军。”

鼓楼广场双方收兵肃立，钦差展开圣旨宣读：“庞太尉通敌构陷，证据确凿，革职流放！”

镜07｜4秒｜中景｜固定
钦差转向文广与围军继续宣读：“杨文广无罪复职，伪令作废，围军即撤！”

镜08｜3秒｜中景插入｜固定
汴京官署外，差役摘下庞太尉官帽并锁紧铁链，他面色阴沉地被押走。

镜09｜3秒｜大远景｜拉镜
围寨主将折起伪令，缉捕军放低弓箭、调转旗帜撤离，苗侗守寨者克制地没有追击。

### 下段｜10–17｜30秒

**节拍**：文广谢族人 → 金花倒下遗言 → 金光送林晓。

镜10｜5秒｜中景｜缓推
文广接过复职文书却先向苗侗族人深深一揖，眼眶发红说：“文广此命，是诸位共同救回的！”

镜11｜3秒｜群像全景｜横移
苗鼓、侗箫与芦笙同时奏响，苗侗族人相互搀扶欢呼，破损旗幡在阳光中翻动。

镜12｜3秒｜中近景｜固定
金花站在人群后望着撤军安心微笑，身体突然一晃，伸向木柱的手差半寸后无力倒下。

镜13｜4秒｜双人近景｜固定
林晓冲来跪地接住金花、含泪喊“金花姐姐”，金花努力睁眼看向围拢的姑娘们。

镜14｜4秒｜金花特写｜缓推
金花望向并列的苗侗乌饭碗，握紧林晓的手，用气声说：“四月初八，是姑娘们护住家人的日子……”

镜15｜3秒｜双人近景｜固定
金花把视线转向围拢的年轻姑娘，唇边带着微笑补充：“温柔，也有锋芒。”

镜16｜5秒｜全景｜缓推
乌饭、盟书和银簪泛起金光包裹林晓，她伸手去抓淡去的金花并高喊：“金花姐姐——！”

镜17｜3秒｜黑屏字幕｜固定
白光吞没广场后切黑，字幕“林晓能回到现代吗？千年之后，还有人记得金花吗？”浮现。

# 第九集：穿越归现代·山河不负

**15镜｜57秒｜上段 27秒 / 下段 30秒**

## 本集导视

本集故事效果：上段让林晓在古碑前醒来，发现今天就是四月初八，节日从传说变成眼前的人。下段用乌饭、族谱和回娘家把千年接上，最后林晓对着镜头把主题说完。本集要治愈，不要再拍战争。

颜色基调：**靛蓝 + 银白 + 暖金**。白天银饰亮、夜里篝火暖，乌饭仍是黑的。节庆红只做点缀，不能变成春节大片。幻影金花保持古代靛蓝，和现代盛装银饰区分开。

布光：上段碑前：与第一集同机位同侧光，手机亮屏是第一粒现代光源。拦门酒、长桌宴用自然顶侧光。下段花园阁、廊桥用黄昏暖光；篝火自下而上；终章山巅用落日逆光，林晓脸要能看清。

镜头拍摄语言：上段醒来用特写转中景，跑向人群用跟随。风景插入（廊桥、湿地）各一镜即走，服务“她看见了什么”。下段蒙太奇可叠化，终章打破第四面墙：林晓直视镜头，只此一次。签名镜头：手机显示四月初八、兄弟背姐进门、直视镜头说风骨。

### 上段｜01–07｜27秒

**节拍**：碑前醒来 → 拦门酒与长桌宴 → 廊桥、湿地、背姐进门。

镜01｜5秒｜特写转中景｜拉镜
现代古碑前林晓猛然睁眼，发现指尖仍触着“杨金花”，亮起的手机显示“农历四月初八”。

镜02｜2秒｜近景｜摇镜
苗鼓芦笙从古巷传来，林晓循声回头，收起手机便提裙跑向人群。

镜03｜3秒｜全景｜横移
寨门前盛装苗家姑娘笑端拦门酒，游客依次接杯，银饰随笑声轻轻摇动。

镜04｜4秒｜中景｜缓推
长桌宴摆满乌饭腊肉，出嫁姑娘与亲人围坐，老人把第一碗乌饭推到姑娘面前。

镜05｜4秒｜大远景｜横移
寨市古镇风雨廊桥横跨巫水，桥上行人与桥下木船交错，古街灯笼逐盏亮起。

镜06｜4秒｜全景｜跟随
花园阁湿地竹排划开倒影，船头姑娘放声唱歌，苗歌在竹林与水面间回荡。

镜07｜5秒｜夜景全景｜环绕
篝火旁人们吹木叶、奏芦笙、跳花跳月，兄弟背姐姐进门，父母含笑迎接。

### 下段｜08–15｜30秒

**节拍**：传说叠化 → 举碗 → 云海见金花 → 直视镜头收题。

镜08｜4秒｜蒙太奇特写｜固定
乌饭制作、旧族谱和杨金花绘画叠化，林晓旁白：“民间相传，杨金花曾用乌饭救回兄长。”

镜09｜4秒｜全景｜横移
不同年龄的姑娘牵孩子回娘家，亲人沿青石巷迎接，旁白：“四月初八，家人接姑娘回家团聚。”

镜10｜3秒｜手部特写｜缓推
林晓端起白瓷碗，黑亮乌饭中央放着翠绿杨桐叶，她低头闻香后轻轻微笑。

镜11｜4秒｜近景｜固定
乌饭碗后苗侗家人共同举杯，旁白：“这一碗饭，记着姑娘的智慧，也记着共同护家的勇气。”

镜12｜5秒｜大远景｜缓升
傍晚黄桑云海被染成暖金，林晓站在山巅，恍惚看见金花从云雾中走来。

镜13｜3秒｜双人远景｜固定
金花隔云海轻轻一笑后化作光点，林晓眼眶发红却平静说：“温柔不是懦弱。”

镜14｜3秒｜中近景｜缓推
林晓转身直视镜头，身后群山炊烟铺开，她坚定说：“一介女子，也能留下千年风骨。”

镜15｜4秒｜大远景字幕｜拉镜
夕阳沉入黄桑群山，字幕“千年乌饭香，岁岁敬温柔”和“湖南绥宁·四八姑娘节”依次出现。

# 第十集：山水绥宁·秘境长歌

**12镜｜58秒｜上段 29秒 / 下段 29秒**

## 本集导视

本集故事效果：没有穿越、没有对白角色。上段用山、林、谷、瀑、上堡把“神奇绿洲”立住；下段用廊桥、湿地、节日和灯火把“人还在这里”立住。要让没看前九集的人也能把它当成绥宁形象片，看过前九集的人能在风景里认出故事发生过的地方。

颜色基调：**翠绿 + 水青 + 暮金**。上段冷绿、湿、深。下段加入黛青建筑和灯火暖金，节日银饰只在人文两镜出现。全片不要滤镜浓到认不出真山水。

布光：上段：晨雾、林中光柱、瀑布迎光；全部自然光，避免正午死白。下段：廊桥与湿地用侧光，傍晚巫水要被夕阳拉成一条金线。人文节日用柔和散射，脸要亲切，不要戏剧轮廓光。

镜头拍摄语言：以航拍、横移、缓升、拉远为主，少特写人脸。每镜只做一个空间运动。旁白压在画面后半拍进入，前半拍先给风景。上段不出现现代广告字，下段最后一镜才出“神奇绿洲·美丽绥宁”。签名镜头：巫水银带、林中光柱、廊桥、航拍拉远收山。

### 上段｜01–06｜29秒

**节拍**：群山巫水 → 大园古寨 → 黄桑 / 曲幽谷 / 瀑布 / 上堡。

镜01｜4秒｜航拍大远景｜横移
清晨镜头越过云雾绥宁群山，巫水如银带穿过绿色谷地；旁白：“这里是湖南绥宁，一座藏在湘西南群山中的小城。”

镜02｜5秒｜航拍转全景｜缓降
晨光从大园古苗寨青瓦上移动，画面掠过窨子屋木门、青砖墙和湿润石巷；旁白：“古巷相连，青瓦之间留着悠长岁月。”

镜03｜5秒｜林海全景｜缓推
黄桑古木间阳光形成光柱，清溪绕过苔藓岩石；旁白：“黄桑林海，古木、清溪和云雾共同守护绿色秘境。”

镜04｜5秒｜栈道全景｜跟随
曲幽谷木栈道贴着峡谷伸向密林，溪水在脚下奔流；旁白：“走进曲幽谷，脚下是流水，身旁是四季青绿。”

镜05｜5秒｜大远景｜固定
六鹅洞瀑布从高处飞落，水雾迎光映出淡淡彩虹；旁白：“飞流而下的瀑布，把山风也染上清凉水汽。”

镜06｜5秒｜航拍大远景｜环绕
上堡山地村寨的木屋、鼓楼、梯田与纵横街巷被群山环抱；旁白：“古老村寨与层层梯田，依山而生。”

### 下段｜07–12｜29秒

**节拍**：廊桥烟火 → 花园阁 → 姑娘节与歌舞 → 暮色拉远。

镜07｜5秒｜全景｜横移
寨市古镇廊桥横跨巫水，居民缓步通行、老街升起炊烟；旁白：“一座廊桥，连起巫水两岸和古城烟火。”

镜08｜5秒｜湿地大远景｜缓推
花园阁水面倒映竹林，白鹭贴水掠过，竹排缓缓划出；旁白：“水清岸绿，是人与自然共同珍惜的家园。”

镜09｜5秒｜人文全景｜跟随
四八姑娘节中盛装姑娘回娘家，亲人端乌饭、兄弟背姐姐进门；旁白：“人们用乌饭和团聚表达敬女、惜女与感恩。”

镜10｜5秒｜快剪组接｜固定
苗歌、芦笙、吹木叶、长桌宴和篝火画面依次交替；旁白：“古老习俗，在今天依然鲜活。”

镜11｜5秒｜傍晚大远景｜横移
夕阳把巫水染金，渔舟划过，远处村寨逐家亮灯；旁白：“山水养育文化，文化也留住乡愁。”

镜12｜4秒｜航拍大远景｜拉镜
镜头从暮色村寨升向无尽群山，字幕“神奇绿洲·美丽绥宁”出现；旁白：“走进绥宁，看见山水，也遇见千年传承。”
