# 第四集六幕 · Midjourney 横屏提示词

上一版加了 `--style raw`、把人缩成点、还写 bursting / 碎栏 / 箭雨切画面，MJ 会把建筑和人体扯碎，火光也会变成霓虹脏橙。

这版改回**完整成片**：
- 不要 `--style raw`
- `--stylize 250`，颜色靠它收拢
- 一句完整画面，人体全身入画，建筑要完整
- 战前用田园电影冷月；开战用朱砂红 + 炭黑 + 琥珀火，不要霓虹

**只复制英文。** 有金花/文广脸就加 `--cref`。先出第一幕，满意后全片加 `--sref`。
