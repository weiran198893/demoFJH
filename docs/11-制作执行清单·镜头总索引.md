## 五、生产阶段划分（按依赖关系，不按日历）

| 阶段 | 任务 | 完成标志 |
| --- | --- | --- |
| **阶段一：定调** | 批次 0–2：风格码、24 张角色图、12 张场景图 | 全部参考图评审通过，风格码锁定不再更改 |
| **阶段二：出图** | 批次 3–11：约 130 张分镜首帧图 | 全片首帧图排成"故事板墙"，通读一遍逻辑与色彩无断裂 |
| **阶段三：动起来** | 115 个镜头的图生视频 | 每集素材齐备，可完成粗剪 |
| **阶段四：声音** | 60 条配音 + 11 段音乐 + 音效包 | 混音完成，手机外放测试通过 |
| **阶段五：成片** | 精剪 + 调色 + 字幕 + 验收 | 8 集通过 `10` 号文件第六章验收清单 |
| **阶段六：物料** | 封面 8 张 + 横屏版 + 剪辑物料 4 版 + 平台文案 | 可发布 |

> **阶段一不通过，绝不进入阶段二。** 角色和风格没锁死就开始出分镜，后面 130 张图会全部返工——这是 AI 短剧最常见、也最昂贵的错误。

## 六、风险清单

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 角色一致性失控 | 全片返工 | 阶段一严格锁定；同批次集中生成 |
| 动作戏崩坏 | E4 不可用 | 已采用"1 秒动作特写组"方案规避（见 EP04 4-06） |
| 群像崩坏 | E7、E8 不可用 | 前景遮挡 + 浅景深 + 剪影三招；必要时改用真实实拍素材做节日段落 |
| 风景镜头不够美 | 文旅方不满意 | E6、E8 的风景镜头可考虑**采用实拍素材或授权空镜**混剪（AI 生成的自然景观真实度仍有上限） |
| 民族元素误植 | 舆情风险 | 服饰按湘西南花苗样式；成片前请当地文化部门审看 |
| 历史人物争议 | 舆情风险 | 反派只称官职；首尾双声明；片尾加"取材民间传说"说明 |
| 台词过密 | 完播率下降 | 全片平均约 2.2 字/秒；正式试录逐镜核验，若超时**优先删解释性台词，不删关键动作** |
